# Open source licenses

Par3 includes third-party software and adapted assets. To read their license and attribution
notices:

- On web and desktop, open **Settings → About**, find **Open source licenses** under **Legal**,
  and select **View licenses**.
- On mobile, open **Settings → About Par3 → Open source licenses**.

The page lists the version when available, license identifier, and the parts of Par3 that include
or use the item. This also covers optional device tools that Par3 installs on demand instead of
bundling. Select a row to read the complete notice text. Use the search field to find a package,
version, license, or app component.
